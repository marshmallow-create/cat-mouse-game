# このプロジェクトでの作業方針

- このプロジェクトは、将来の会社用システム開発に向けた学習教材でもある。
- 関連作業を始めるときは `Markdown/LEARNING_PLAN.md` を読み、合意済みの構成・現在の進捗・次の段階を確認する。
- 構成は既存のHTML・CSS・JavaScript、Node.jsのサーバー、PostgreSQLの共有データベース。
- 一度に多くの段階を実装せず、依頼された段階を完成・確認して進捗を記録する。
- 実装の前後に、日本語で初心者向けの解説を付ける。目的、データの流れ、新しい用語、変更点、起動・確認方法を具体例で説明する。
- 利用者が自分で試せる確認例を添え、学んだ内容が業務システムのどこに生かせるかを説明する。
- 完了扱いにするのは、その段階の到達点を確認できた場合だけ。未確認の内容を明記する。
- データベースの接続情報はサーバー側で管理し、ブラウザに含めない。
- 既存のゲームや利用者による変更を確認してから編集する。
- 利用者の最新の指示を、この計画より優先する。
